# Obstacle Avoiding, Bluetooth & Voice Control Robot Car

## 📌 Project Overview

This project is an Arduino-based smart robot car designed with three main functions:

- Obstacle Avoidance
- Bluetooth Control
- Voice Control

The robot can detect obstacles using an ultrasonic sensor and can also be controlled wirelessly through Bluetooth and voice commands.

## 🚀 Features

- Automatic obstacle detection and avoidance
- Bluetooth-based wireless control
- Voice command control
- Forward, backward, left and right movement
- Servo-mounted ultrasonic sensor for obstacle detection
- Arduino-based control system

## 🔧 Components Used

- Arduino Uno
- L293D Motor Driver
- DC Gear Motors
- Robot Car Chassis
- Ultrasonic Sensor (HC-SR04)
- Servo Motor
- HC-05 Bluetooth Module
- Robot Wheels
- Battery Pack
- Jumper Wires

## 💻 Technologies Used

- Arduino
- Embedded C / C++
- Ultrasonic sensing
- Bluetooth communication
- Motor control

## ⚙️ Working

The ultrasonic sensor continuously measures the distance in front of the robot. When an obstacle is detected within a certain distance, the robot changes its direction to avoid the obstacle.

In Bluetooth control mode, commands received from a mobile device are processed by the Arduino to control the robot's movement.

Voice control allows the robot to respond to voice-based movement commands through a compatible Bluetooth control setup.
